# LEKALO ZHIIDE — STAGE 5.11: Инструкция по передаче проекта Адилету

**Кому:** Администратору каталога Адилету  
**Назначение:** Практическое руководство по наполнению каталога выкроек, пакетной загрузке PDF (Bulk Upload) и контролю качества перед публикацией.  
**Среда работы:** Административная панель Lekalo Zhiide (`/admin`)

---

## 1. Что Адилет может и должен делать

Адилет наделен правами **Администратора каталога** (`ROLE_ADMIN`) и выполняет следующие задачи:
1. Авторизовываться в административной панели (`/admin`).
2. Просматривать список товаров каталога (`/admin/products`).
3. Переходить на страницу управления файлами товара: `/admin/products/[id]/files`.
4. Загружать готовые производственные PDF-выкройки через интерфейс **Bulk Upload** (пакетная загрузка) или индивидуальную загрузку по вариантам.
5. Проверять статус загруженных файлов и их соответствие стандартам (размер файла, валидация сигнатуры, доступность для покупки).
6. Проверять тестовый квадрат (100×100 мм) и разметку выкройки перед подтверждением готовности.

## 2. Стандарт именования файлов (Strict Naming Standard)

Модуль **Bulk Upload** автоматически распознает размер, ростовку и формат выкройки по имени файла. Если имя файла не соответствует стандарту, файл будет отклонен с ошибкой `FILENAME_MISMATCH`.

### 2.1. Шаблон имени файла для индивидуального варианта:
```text
{slug}-{size}-{height}-{format}.pdf
```

- **`{slug}`** — транслитерированное кодовое имя товара из каталога (ровно так, как в URL товара).  
  *Пример:* `palto-oversayz-cholpon`, `zhaket-safari-ayday`.
- **`{size}`** — размер одежды (строго из размерной сетки товара):  
  *Примеры:* `40`, `42`, `44`, `46`, `48`, `50`, `52`, `54`.
- **`{height}`** — диапазон ростовки:  
  *Примеры:* `164-170`, `158-164`, `170-176`.
- **`{format}`** — формат печати (строго один из двух):  
  - `A4` — для печати на стандартном домашнем принтере А4 с полями склейки.  
  - `PLOTTER_900` — для широкоформатной плоттерной печати (ширина рулона 900 мм).

#### Примеры корректных имен:
- `palto-oversayz-cholpon-42-164-170-A4.pdf`
- `palto-oversayz-cholpon-42-164-170-PLOTTER_900.pdf`
- `zhaket-safari-ayday-48-164-170-A4.pdf`

### 2.2. Шаблон имени для полного комплекта всех размеров (Bundle):
```text
{slug}-ALL-{height}-{format}.pdf
```
*Пример:* `palto-oversayz-cholpon-ALL-164-170-A4.pdf`

## 3. Критерии качества настоящего PDF (Quality Gate)

Перед загрузкой каждого файла Адилет обязан убедиться, что файл соответствует **Техническому стандарту Stage 5.2**:
1. **Настоящий PDF:** Файл должен быть скомпилирован САПР (Grafis, CLO3D, Gerber или Adobe Illustrator) и содержать валидные сигнатуры `%PDF-` и `%%EOF`.
2. **Контрольный квадрат:** На первой странице (в формате А4) или в начале рулона (Plotter 900) должен присутствовать контрольный проверочный квадрат строго **100 × 100 мм**.
3. **Размер файла:** Чистовой производственный файл всегда превышает **50 КБ** (часто от 500 КБ до 15 МБ). Сервер автоматически отклоняет любые файлы меньше **1024 байт** (`FILE_TOO_SMALL` / `STUB_FILE_REJECTED`).
4. **Поля и склейка А4:** Сетка листов содержит рамки и алфавитно-цифровую маркировку склейки (например, ряд А листы 1–4, ряд B листы 1–4).
5. **Плоттер 900 мм:** Ширина полотна строго до 900 мм, непрерывная раскладка без разрывов.

## 4. Пошаговая инструкция по пакетной загрузке (Bulk Upload)

1. Войдите в панель администратора: `/admin`.
2. Откройте нужный товар из списка (например, *Пальто оверсайз Чолпон*).
3. Нажмите вкладку/кнопку **«Файлы выкроек»** (переход на `/admin/products/[id]/files`).
4. В секции **«Массовая загрузка выкроек (Bulk Upload)»**:
   - Перетащите (Drag-and-Drop) или выберите через диалог пачку PDF-файлов для этой модели (например, 6 файлов).
   - Система отобразит список распознанных файлов с индикатором варианта, к которому привяжется файл.
5. Если все файлы определены верно, нажмите **«Загрузить все файлы»**.
6. Дождитесь окончания загрузки:
   - Успешно загруженные файлы подсветятся зеленым бейджем **«Готово к выдаче» (Ready)**.
   - Сервер автоматически переведет соответствующие варианты в статус `isAvailable: true`.

## 5. Проверка результата после загрузки

После загрузки проверьте страницу товара:
1. В таблице вариантов товара убедитесь, что:
   - Отображается актуальный размер загруженного файла (например, `2.4 MB`).
   - Отображается версия файла (например, `v1`).
   - Статус варианта изменился на **Активен / Готов к продаже**.
2. Скачайте загруженный файл по ссылке «Скачать контрольную копию» и откройте в Adobe Acrobat / PDF Reader:
   - Проверьте масштаб печати: выставьте в диалоге печати «100%» или «Реальный размер».
   - Измерьте контрольный квадрат линейкой: строго 10 см × 10 см.
3. Проверьте витрину магазина:
   - Откройте карточку товара в публичном каталоге (`/catalog/{slug}`).
   - Выберите загруженный размер и формат: кнопка «В корзину» должна стать **активной**.

## 6. Что делать при возникновении ошибок

| Ошибка на экране | Причина ошибки | Что необходимо сделать |
| :--- | :--- | :--- |
| **`FILENAME_MISMATCH`** | Имя файла не соответствует формату `{slug}-{size}-{height}-{format}.pdf` | Переименовать файл строго по шаблону. Проверить дефисы и регистр букв. |
| **`INVALID_PDF_SIGNATURE`** | Файл поврежден или не является валидным PDF (например, сохранен как HTML или DOCX) | Переэкспортировать файл из САПР в стандартный PDF (ISO 32000-1). |
| **`FILE_TOO_SMALL`** | Размер файла меньше 1 КБ (демо-заглушка или пустой файл) | Загрузить полный файл выкройки от конструктора. |
| **`FILE_ALREADY_EXISTS`** | Для этого варианта уже загружен файл, а флаг перезаписи выключен | Если требуется обновить выкройку на новую версию, отметьте галочку **«Разрешить перезапись (allowOverwrite)»**. Версия повысится до `v2`. |
| **`SERVER_ERROR`** | Временный сбой связи с хранилищем Supabase S3 | Подождать 1 минуту и повторить загрузку файла. |

## 7. Категорически запрещенные действия

Для сохранения стабильности и безопасности проекта Адилету **строго запрещается**:
1. ❌ **Загружать файлы-заглушки или пустые тестовые документы.** Защита Purchase Guard сразу отклонит их, либо клиенты получат брак.
2. ❌ **Удалять товары и категории из каталога без согласования с тимлидом.**
3. ❌ **Изменять системные конфигурации, переменные окружения и ключи доступа.**
4. ❌ **Вручную активировать статус доступности в обход загрузки настоящего PDF.**
5. ❌ **Публиковать товар в каталоге, если для него не загружен базовый комплект ходовых размеров.**
