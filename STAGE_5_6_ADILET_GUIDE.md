# LEKALO ZHIIDE — РУКОВОДСТВО АДИЛЕТА
## ПРАКТИЧЕСКАЯ ИНСТРУКЦИЯ ПО МАССОВОЙ ЗАГРУЗКЕ ВЫКРОЕК (BULK UPLOAD)

**Версия:** 3.0 (Stage 5.6 Bulk PDF Upload)  
**Для кого:** Адилет (Администратор LEKALO ZHIIDE)  
**Назначение:** Быстрая и безопасная загрузка выкроек для всех 23 товаров и 183 вариантов каталога.

---

## 1. Зачем нужна массовая загрузка

Раньше для загрузки файлов требовалось открывать модальное окно для каждого отдельного размера и формата. Теперь вы можете **одним движением перетащить всю партию файлов модели (например, все 12 размеров пальто Чолпон)**, система автоматически распознает размеры, проверит их и загрузит в защищенное хранилище за несколько секунд.

---

## 2. Пошаговый регламент загрузки партии (7 шагов)

### Шаг 1. Откройте страницу файлов товара
1. Перейдите в панель управления: `http://localhost:3000/admin`.
2. В боковом меню выберите **«Товары»** (`/admin/products`).
3. Найдите нужный товар (например, товар №23 «Пальто оверсайз Чолпон») и нажмите на значок **«Файлы»** (ссылка `/admin/products/{id}/files`).

### Шаг 2. Перетащите PDF-файлы в зону загрузки
В верхней части вкладки **«PDF-выкройки»** расположена секция **«Массовая загрузка PDF-выкроек (Bulk Upload)»**:
- Откройте папку на вашем компьютере с готовыми выкройками от конструктора.
- Выделите файлы (до 50 штук) и **перетащите их мышью в пунктирную рамку Drag-and-Drop**.
- Или просто кликните по рамке и выберите файлы через диалоговое окно проводника.

### Шаг 3. Изучите таблицу автоматического сопоставления
Как только файлы добавлены, система мгновенно строит таблицу предпросмотра:
- **Файл:** имя файла и его размер.
- **Найденный вариант:** распознанный размер, рост, формат и SKU.
- **Проверка / Статус:** цветной статус готовности файла к загрузке.
- **Действие:** кнопка удаления файла из очереди или чекбокс подтверждения замены.

### Шаг 4. Расшифровка статусов и исправление ошибок
Перед загрузкой проверьте статусы:

| Статус | Цвет | Что означает | Что нужно сделать Адилету |
| :---: | :---: | :--- | :--- |
| **`READY`** | Зеленый | Имя файла строго совпадает со стандартом, вариант найден, файла в базе еще нет | Ничего не нужно делать. Файл полностью готов к отправке |
| **`ALREADY_EXISTS`** | Янтарный | Для этого варианта выкройка **уже была загружена ранее** | Если конструктор прислал обновленную версию, отметьте галочку **«Заменить»** (или общую галочку «Заменить все существующие»). Без этой отметки файл не будет перезаписан |
| **`WRONG_FILENAME`** | Красный | Имя файла не начинается со слага текущего товара или искажено | Переименуйте файл на компьютере по стандарту `{slug}-{size}-{height}-{format}.pdf` и добавьте снова |
| **`UNKNOWN_VARIANT`** | Красный | Указанный в имени размер или формат не существует у этой модели | Проверьте, правильный ли товар открыт, или сгенерируйте недостающий размер в матрице |
| **`DUPLICATE`** | Оранжевый | В партии присутствуют два одинаковых файла или два файла для одного SKU | Удалите лишний файл крестиком в правой колонке |
| **`INVALID_PDF`** | Красный | Файл пустой (0 байт), больше 30 МБ или не является PDF | Запросите у конструктора корректный скомпилированный PDF |

> **ВАЖНО:** Файлы со статусами ошибок (`WRONG_FILENAME`, `UNKNOWN_VARIANT`, `DUPLICATE`, `INVALID_PDF`) **автоматически исключаются** из отправки и не могут повредить базу данных.

### Шаг 5. Подтвердите замену (если требуется)
Если вы обновляете выкройки:
- Для отдельных файлов: установите флажок **«Заменить»** в строке файла.
- Для всей партии сразу: установите галочку **«Заменить все существующие»** над таблицей.

### Шаг 6. Запустите пакетную загрузку
1. В поле **«Комментарий к версии»** укажите причину загрузки, например:
   `Пакетный релиз выкроек v1 от конструктора`
2. Нажмите синюю кнопку **«Загрузить проверенные файлы (N)»**.
3. Дождитесь завершения (появится анимация загрузки).

### Шаг 7. Проверьте итоговый отчет
После завершения над таблицей появится цветной отчет сервера:
- **Зеленый баннер:** *«Результат партии: успешно N из N файлов»*. В таблице в колонке статуса появится зеленая отметка `✓ Загружен (v1)`.
- Матрица вариантов ниже автоматически обновится, окрасив строки в зеленый цвет готовности, а индикатор готовности комплекта ALL пересчитает процент укомплектованности.

## 3. Памятка по каноническим именам файлов

Формула:
$$\mathbf{\{slug\}-\{size\}-\{height\}-\{format\}.pdf}$$

### Примеры для пальто «Чолпон» (`palto-oversayz-cholpon`):
- `palto-oversayz-cholpon-42-164-170-A4.pdf` (А4)
- `palto-oversayz-cholpon-42-164-170-PLOTTER_900.pdf` (Плоттер)
- `palto-oversayz-cholpon-ALL-164-170-A4.pdf` (Комплект ALL, А4)

---

## 4. Чек-лист перед запуском пакетной загрузки

- [ ] В партии не более 50 файлов.
- [ ] Суммарный объем партии не превышает 150 МБ.
- [ ] Все имена начинаются с точного слага товара.
- [ ] В таблице предпросмотра горит индикатор `READY` для новых файлов.
- [ ] Для обновляемых файлов отмечен чекбокс подтверждения замены.
- [ ] Нет красных статусов ошибок (`WRONG_FILENAME` / `DUPLICATE`).
- [ ] Заполнен комментарий к версии.
