## 2. Детальный разбор обнаруженных пробелов (Admin UI Gaps)

### GAP 1: Отсутствие управления справочником ростовок (`/admin/heights`)
- **Где обнаружено**: [frontend/src/app/admin/products/new/page.tsx#L37](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/frontend/src/app/admin/products/new/page.tsx#L37)
- **Суть проблемы**: В коде страницы создания товара объявлен статический массив:
  ```typescript
  const HEIGHTS = ["158-164", "164-170", "170-176"];
  ```
  В базе данных таблица `heights` динамическая, но у неё нет ни админских API (CRUD), ни страницы `/admin/heights`. Если конструктор подготовит выкройку на ростовку `150-156` или `176-182`, Адилет не сможет добавить её через админку.
- **Риск**: Блокировка добавления нестандартных ростовок без участия бэкенд-разработчика.
- **Приоритет**: **P1**.

---

### GAP 2: Отсутствие управления справочником форматов (`/admin/formats`)
- **Где обнаружено**: [frontend/src/app/admin/products/new/page.tsx#L38-41](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/frontend/src/app/admin/products/new/page.tsx#L38-41)
- **Суть проблемы**: Форматы захардкожены в константе:
  ```typescript
  const FORMATS = [
    { code: "A4", label: "А4 (бытовой принтер)" },
    { code: "PLOTTER_900", label: "Плоттер 900 мм" },
  ];
  ```
  При этом в БД есть формат `LETTER`, но в админке его нет. Если появится формат `A0` или `PLOTTER_1200`, Адилет не сможет добавить его самостоятельно.
- **Риск**: Невозможность расширения форматов печати без изменения исходного кода.
- **Приоритет**: **P1**.

---

### GAP 3: Отсутствие загрузки инструкций по пошиву через админку
- **Где обнаружено**: [frontend/src/app/admin/products/[id]/files/page.tsx](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/frontend/src/app/admin/products/[id]/files/page.tsx), [src/modules/storage/storage-admin.controller.ts](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/src/modules/storage/storage-admin.controller.ts)
- **Суть проблемы**: 
  - В базе данных создана модель `ProductInstruction`.
  - В кабинете покупателя реализован эндпоинт `GET /api/v1/cabinet/instructions/:id/download-url` с проверкой покупки.
  - Однако в панели управления файлами товара (`[id]/files`) есть только вкладки «Выкройки (PDF)» и «Изображения». Вкладка «Инструкция по пошиву» отсутствует.
  - На бэкенде отсутствует эндпоинт `POST /api/v1/admin/storage/upload-instruction`.
- **Риск**: Покупатель после оплаты не сможет скачать пошаговую инструкцию по пошиву, так как администратор не имеет инструмента для её загрузки.
- **Приоритет**: **P1**.

---

### GAP 4: Невозможность задать разные цены для форматов в админке
- **Где обнаружено**: [frontend/src/app/admin/products/new/page.tsx#L61-63](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/frontend/src/app/admin/products/new/page.tsx#L61-63), [ProductDetailView.tsx#L650](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/frontend/src/app/catalog/[slug]/ProductDetailView.tsx#L650)
- **Суть проблемы**: 
  - В базе данных у каждого варианта `ProductVariant` есть колонка `priceOverride Decimal?`.
  - Корзина и чекаут поддерживают `priceOverride`.
  - Но в формах создания и редактирования товара присутствуют только два поля: `basePrice` («Базовая цена») и `bundlePrice` («Цена комплекта»).
  - Задать, например, А4 = 450 сом, а Плоттер = 600 сом через интерфейс невозможно. На витрине цена для обоих форматов отображается одинаковой.
- **Риск**: Несоответствие бизнес-модели, если печать плоттера должна стоить дороже А4.
- **Приоритет**: **P1**.

---

### GAP 5: Риск поломки покупки комплекта при отсутствии варианта `ALL`
- **Где обнаружено**: [frontend/src/app/catalog/[slug]/ProductDetailView.tsx#L335-338](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/frontend/src/app/catalog/[slug]/ProductDetailView.tsx#L335-338), [ProductDetailView.tsx#L506-513](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/frontend/src/app/catalog/[slug]/ProductDetailView.tsx#L506-513)
- **Суть проблемы**:
  - На витрине переключатель «Все размеры (комплект)» активен, если `hasBundleOption = true` и задан `bundlePrice`.
  - При клике «В корзину» фронтенд ищет вариант с кодом размера `ALL` (`bundleVariantList`).
  - Если администратор при создании товара не включил размер `ALL` в матрицу (а по умолчанию выбраны только 42, 44, 46, 48, 50), то `bundleVariantList` пуст!
  - В результате `activeVariant` становится `undefined`, и при клике «В корзину» покупатель получает ошибку: *«Пожалуйста, выберите доступный размер и формат выкройки»*.
- **Риск**: Срыв покупки комплекта покупателем при корректно заполненной цене комплекта в админке.
- **Приоритет**: **P0 (Критическая целостность покупки)**.

---

### GAP 6: Отсутствие прямой загрузки видеофайлов
- **Где обнаружено**: [src/modules/storage/storage-admin.controller.ts#L31](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/src/modules/storage/storage-admin.controller.ts#L31)
- **Суть проблемы**: Разрешены только `image/jpeg, image/png, image/webp` и `application/pdf`. Администратор может указать только внешнюю ссылку на видео (YouTube embed). Загрузить файл `.mp4` или `.mov` с компьютера в S3 нельзя.
- **Приоритет**: **P2**.

---

### GAP 7: Отсутствие планирования даты старта акции (`discountFrom`)
- **Где обнаружено**: [prisma/schema.prisma#L105-106](file:///C:/Users/ASUS/.gemini/antigravity/scratch/lekalo-zhiide/prisma/schema.prisma#L105-106)
- **Суть проблемы**: В схеме присутствует только дата окончания скидки (`discountUntil`). Скидка вступает в силу сразу после сохранения акционной цены. Нельзя настроить акцию «с 1 декабря по 15 декабря».
- **Приоритет**: **P2**.

## 3. Резюме для руководства
Интерфейс админ-панели покрывает **70%** повседневных задач контент-менеджера. Адилет может автономно наполнять каталог товарами, ценами, описаниями, фотографиями и PDF-файлами выкроек.

Однако для устранения бизнес-рисков и достижения 100% соответствия ТЗ требуются точечные доработки:
1. Автоматическое создание варианта `ALL` при генерации матрицы (защита от P0-ошибки покупки комплекта).
2. Добавление загрузчика PDF-инструкций в админку.
3. Добавление админ-справочников ростовок и форматов.
4. Добавление полей цен по форматам печати.
