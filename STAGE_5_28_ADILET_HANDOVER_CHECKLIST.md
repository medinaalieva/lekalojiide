## 1. Введение

Адилет, платформа **LEKALO ZHIIDE** разработана таким образом, чтобы вы могли полностью управлять интернет-магазином выкроек самостоятельно — **без программистов, без знания кода и без прямого доступа к базе данных**.

Все рутинные операции выполняются через визуальную панель управления (`/admin`).

## 3. Чек-лист подготовки товара к открытию продаж (10 шагов)

Выполняйте этот чек-лист для каждого из 23 товаров каталога строго по порядку:

- [ ] **Шаг 1. Проверка карточки товара:** Название написано без опечаток, категория выбрана верно, указан корректный уровень сложности.
- [ ] **Шаг 2. Фотографии:** Загружено не менее 2–3 качественных фото, главное фото назначено обложкой (`isCover: true`).
- [ ] **Шаг 3. CAD-чертеж:** Прикреплен технический рисунок модели. Проверен просмотр чертежа через кнопку «Увеличить чертеж» в браузере.
- [ ] **Шаг 4. Мерки и расход:** Заполнены поля «Расход ткани», «Фурнитура», «Мерки готового изделия» на основе данных от конструктора.
- [ ] **Шаг 5. Генерация вариантов:** Сгенерированы варианты для нужных размеров (например, 42, 44, 46, 48) и форматов (А4 и Плоттер 900).
- [ ] **Шаг 6. Дифференциальные цены:** Проверено, что на плоттер задана корректная наценка (если требуется), а также включен бандл «Все размеры» со скидкой.
- [ ] **Шаг 7. Загрузка чистовых PDF выкроек:** Для каждого сгенерированного варианта загружен оригинальный PDF от конструктора (не заглушка!).
- [ ] **Шаг 8. Загрузка инструкции:** Прикреплен чистовой PDF инструкции по пошиву.
- [ ] **Шаг 9. Контрольная тестовая печать:** Распечатан 1-й лист формата А4, тестовый квадрат измерен линейкой (строго 100 × 100 мм).
- [ ] **Шаг 10. Публикация:** Переключен статус активности товара `isActive: true`. Товар готов к приему платежей!

## 4. Что необходимо запросить у конструктора лекал

Для каждого из 23 изделий каталога конструктор должен предоставить следующий обязательный комплект:

1. **Файлы лекал в формате PDF для А4:**
   - Отдельный файл на каждый размер и рост.
   - С калибровочным квадратом 10 × 10 см на первой странице.
   - С рамками для склейки и полями.
2. **Файлы лекал в формате PDF для Плоттера:**
   - Отдельный файл на рулон 900 мм (или 610 мм).
   - Непрерывная раскладка без разрывов деталей.
3. **Иллюстрированная инструкция по пошиву (PDF):**
   - Спецификация деталей кроя.
   - Пошаговые схемы сборки узлов.
4. **Технический паспорт модели:**
   - Норма расхода основной и подкладочной ткани для каждой группы размеров.
   - Спецификация клеевых материалов и фурнитуры (пуговицы, молнии, кнопки).
   - Таблица прибавок и контрольных измерений готового изделия.

## 5. Главные правила безопасности для Адилета

1. **Никогда не загружайте файлы меньше 1 КБ или пустые документы:** Защитная система платформы (Purchase Guard) автоматически распознает их как брак и заблокирует продажу для покупателей.
2. **Если покупатель жалуется на ошибку при скачивании:** Зайдите в `/admin/products/[id]/files` и убедитесь, что у нужного размера горит статус «Файл прикреплен и активен».
3. **Изменение цен в каталоге безопасно:** Изменение цен в карточке товара никогда не ломает уже оформленные заказы покупателей (цены купленных товаров замораживаются навечно в чеке).
