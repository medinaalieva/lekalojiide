# LEKALO ZHIIDE — ИНСТРУКЦИЯ ДЛЯ АДИЛЕТА
## ПРАКТИЧЕСКОЕ РУКОВОДСТВО ПО БЕЗОПАСНОЙ ЗАГРУЗКЕ PDF-ВЫКРОЕК

**Версия регламента:** 2.0 (по результатам Stage 5.5 Secure PDF Upload Patch)  
**Кому адресовано:** Адилет (Администратор интернет-магазина LEKALO ZHIIDE)  
**Цель:** Исключить ошибки привязки файлов, повреждение данных и загрузку некорректных форматов.

---

## 1. Главные правила безопасности (Что изменилось)

В систему внедрена строгая двухфакторная защита от ошибок:
1. **Защита по содержимому (Backend):** Сервер принимает **только настоящие PDF-файлы** стандарта ISO 32000-1. Переименованные документы Word, текстовые файлы, HTML, ZIP-архивы или пустые файлы будут **автоматически отклонены**.
2. **Защита по имени (Frontend + Backend):** Имя каждого PDF-файла обязано **символ в символ** совпадать со стандартом каталога. Если вы случайно выберете файл 48 размера для строки 42 размера — система заблокирует кнопку загрузки и не позволит сделать ошибку.

---

## 2. Стандарт канонического наименования файлов

Каждый файл выкройки перед загрузкой должен называться по единой формуле:

$$\mathbf{\{slug\}-\{size\}-\{height\}-\{format\}.pdf}$$

### Элементы формулы:
1. **`{slug}`** — официальный системный слаг товара на латинице (например, `palto-oversayz-cholpon`).
2. **`{size}`** — код размера (`40`, `42`, `44`, `46`, `48`, `50`, `52`, `54`) или `ALL` (для размерных комплектов).
3. **`{height}`** — диапазон роста (`164-170`).
4. **`{format}`** — формат печати:
   - `A4` — для домашней печати на принтере A4;
   - `PLOTTER_900` — для печати на широкоформатном плоттере (рулон 900 мм).
5. **`.pdf`** — расширение только строчными (маленькими) буквами.

### Примеры правильных имен:
- `palto-oversayz-cholpon-42-164-170-A4.pdf` — Пальто Чолпон, размер 42, рост 164-170, А4.
- `palto-oversayz-cholpon-42-164-170-PLOTTER_900.pdf` — Пальто Чолпон, размер 42, рост 164-170, плоттер.
- `plate-midi-aida-s-zapakhom-ALL-164-170-A4.pdf` — Платье Аида, комплект всех размеров, А4.

### Примеры недопустимых имен (будут отклонены):
- `пальто_42.pdf` — кириллица и неполное имя (ОШИБКА).
- `cholpon-42.pdf` — усеченный слаг (ОШИБКА).
- `palto-oversayz-cholpon-42-164-170-a4.PDF` — заглавное расширение `.PDF` (ОШИБКА).
- `palto-oversayz-cholpon-48-164-170-A4.pdf` — попытка загрузить файл 48 размера в строку 42 размера (ОШИБКА).

## 3. Пошаговый процесс загрузки выкройки в панели управления

### Шаг 1. Перейдите на страницу файлов товара
1. Войдите в панель управления: `http://localhost:3000/admin`.
2. В боковом меню выберите **«Товары»** (`/admin/products`).
3. Найдите нужный товар (например, товар №23 «Пальто оверсайз Чолпон») и нажмите на значок **«Файлы»** (или ссылку `/admin/products/{id}/files`).

### Шаг 2. Откройте окно загрузки
Нажмите кнопку **«+ Загрузить PDF-файл»** в правом верхнем углу.

### Шаг 3. Выберите нужный вариант
В поле **«Вариант выкройки (Размер / Рост / Формат)»** выберите строку, для которой загружается лекало (например, `42 / 164-170 / A4`).

### Шаг 4. Обратите внимание на синюю карточку подсказки
Как только вариант выбран, в окне появится синий блок:
> **Ожидаемое каноническое имя файла:**  
> `palto-oversayz-cholpon-42-164-170-A4.pdf`  
> *(Рядом расположена кнопка **«Скопировать имя»**)*.

Нажмите «Скопировать имя» и, если файл на вашем компьютере называется иначе, переименуйте его.

### Шаг 5. Выберите файл на компьютере
Нажмите **«Выберите файл»** и укажите подготовленный PDF.

### Шаг 6. Сверьте индикатор статуса
Система мгновенно проверит имя файла:
- **Если имя правильное:** появится зеленый бейдж:
  > *«Имя файла совпадает со стандартом каталога»*
  > Кнопка **«Загрузить выкройку»** станет активной (синей).
- **Если в имени ошибка или выбран не тот файл:** появится красная плашка:
  > *«Имя файла не совпадает со стандартом! Выбран: {ваше_имя}, Ожидается: {каноническое_имя}»*
  > Кнопка **«Загрузить выкройку»** останется **заблокированной (серой)**.

### Шаг 7. Укажите комментарий к версии (по желанию)
В поле **«Комментарий к версии»** можно ввести пояснение, например:
- `v1: Первоначальный релиз выкройки от конструктора`
- `v2: Исправлены припуски на подгибку низа`

### Шаг 8. Подтвердите загрузку
Нажмите кнопку **«Загрузить выкройку»**.
После завершения появится зеленое уведомление, и файл появится в таблице версий варианта.

## 4. Расшифровка возможных ошибок сервера

| Код ошибки сервера | Причина | Что сделать Адилету |
| :--- | :--- | :--- |
| `FILENAME_VARIANT_MISMATCH` | Имя файла не совпадает с выбранным вариантом | Скопируйте ожидаемое имя из синей подсказки и переименуйте файл на компьютере |
| `INVALID_FILE_TYPE` | Файл является HTML-страницей, ZIP-архивом или текстовым документом | Убедитесь, что конструктор передал именно скомпилированный PDF, а не веб-страницу или архив |
| `EMPTY_FILE` | Файл имеет размер 0 байт (пустой) | Файл не сохранился при экспорте. Попросите конструктора пересохранить PDF |
| `CORRUPTED_PDF_STRUCTURE` | Файл поврежден или скачался не до конца (нет метки окончания `%%EOF`) | Перекачайте файл от конструктора заново или откройте его в Adobe Acrobat и сохраните повторно |
| `CORRUPTED_OR_INVALID_PDF` | Файл слишком маленький (< 120 байт) или является пустой заглушкой | Файл не содержит страниц лекал. Загрузите настоящий рабочий PDF |

## 5. Чек-лист перед нажатием кнопки «Загрузить»

- [ ] PDF открывается в Adobe Acrobat / браузере без предупреждений об ошибках.
- [ ] На первой странице присутствует контрольный тестовый квадрат 100×100 мм.
- [ ] Физический замер контрольного квадрата линейкой при 100% масштабе печати дает ровно 100×100 мм.
- [ ] Для формата A4 проверены рамки склейки и нумерация листов.
- [ ] Для формата PLOTTER_900 проверена ширина рулона (до 900 мм).
- [ ] Имя файла строго скопировано из карточки варианта.
- [ ] В модальном окне горит зеленый бейдж соответствия.
