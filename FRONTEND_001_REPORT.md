## 1. Архитектура и стек технологий

В соответствии с `ARCHITECTURE.md` и `TECH_STACK.md` (Архитектура А — раздельная организация SSR витрины и REST API сервиса) реализовано клиентское приложение:

| Компонент | Технологический выбор | Обоснование |
| :--- | :--- | :--- |
| **Фреймворк** | **Next.js (App Router) v13.5.6** | Полная совместимость со средой Node.js 18.12.1 хоста, современный App Router, быстрый SSR и статическая генерация страниц. |
| **Библиотека UI** | **React 18.2.0** | Стабильный рендеринг компонентов, Context API для клиентского состояния авторизации и корзины. |
| **Стилизация** | **Tailwind CSS + PostCSS + Autoprefixer** | Премиальный визуальный стиль Digital Fashion и швейных ателье (палитра `brand` и `atelier`, типографика, адаптивная верстка). |
| **Иконки** | **Lucide React** | Легковесный векторный набор иконок (корзина, ножницы, файлы, загрузка, безопасность). |
| **Сетевой клиент** | **Fetch API с поддержкой JWT Bearer и прокси-реврайтом** | Автоматическая маршрутизация `/api/v1/*` на NestJS backend (`http://127.0.0.1:4000/api/v1/*`) без конфликтов CORS. |
| **Расположение** | Директория `frontend/` в корне репозитория | Изолированная структура, независимый жизненный цикл сборки. |

## 2. Реализованные страницы и компоненты

### 2.1. Основные пользовательские маршруты (App Router)

1. **Главная страница (`/`) — `src/app/page.tsx`**:
   - Hero-секция с позиционированием: *«Безупречная посадка в каждом стежке — цифровое ателье выкроек»*.
   - Ключевые преимущества (A4 и плоттер 600/900 мм, оплата в сомах KGS, мгновенная выдача PDF).
   - Сетка категорий выкроек с динамической загрузкой с бэкенда.
   - Витрина популярных моделей и новинок.
   - Блок стандартов качества (отшив в реальной ткани, конструктивная точность, бессрочный доступ).

2. **Каталог цифровых выкроек (`/catalog`) — `src/app/catalog/page.tsx`**:
   - Живой поиск по названию и описанию моделей.
   - Фильтры по категориям, размерам (40–54 RU), ростовкам (158–176 см), форматам печати (A4, плоттер).
   - Сортировка по дате, цене (возрастание/убывание) и алфавиту.
   - Карточки товаров с ценами в сомах, бейджами сложности и статусом наличия.
   - Постраничная пагинация и сброс активных фильтров.

3. **Карточка модели (`/catalog/[slug]`) — `src/app/catalog/[slug]/page.tsx`**:
   - Фотогалерея (главный ракурс, превью-слайды).
   - Интерактивный конфигуратор варианта: выбор размера (RU), ростовой группы (см) и формата печати (A4 / плоттер).
   - Динамический пересчет цены выбранного варианта в KGS.
   - Описание модели, нормы расхода и рекомендации по выбору ткани.
   - Список входящих в комплект пошаговых PDF-инструкций по сборке и пошиву.
   - Кнопка «Добавить в корзину» с обратной связью и модальным окном приглашения к авторизации для гостей.

4. **Корзина покупателя (`/cart`) — `src/app/cart/page.tsx`**:
   - Список выбранных выкроек с параметрами (размер, рост, формат печати).
   - Удаление товаров поштучно и полная очистка корзины.
   - Расчет итоговой суммы в сомах (KGS).
   - Переход к процедуре оформления заказа.

5. **Оформление заказа (`/checkout`) — `src/app/checkout/page.tsx`**:
   - Форма контактов покупателя (Email, телефон, примечание к заказу).
   - Выбор способов онлайн-оплаты в KGS (Элкарт, Visa, MasterCard, MBank, О!Деньги).
   - Создание заказа на бэкенде через `POST /api/v1/orders/checkout`.
   - Экран подтверждения с номером заказа и ссылкой на защищенный платежный шлюз.

6. **Аутентификация (`/login`, `/register`) — `src/app/login/`, `src/app/register/`**:
   - Формы входа и регистрации покупателей с валидацией email, телефона и пароля.
   - Сохранение JWT токена в безопасном хранилище клиентской сессии.
   - Автоматический редирект в личный кабинет.

7. **Личный кабинет покупателя (`/cabinet`) — `src/app/cabinet/page.tsx`**:
   - Сводка профиля пользователя.
   - Быстрый доступ к разделам «Мои выкройки», «Центр скачивания» и каталогу.
   - История заказов покупателя с бейджами статусов оплаты (`Оплачен`, `Ожидает оплаты`, `Отменен`).

8. **Библиотека «Мои выкройки» (`/cabinet/library`) — `src/app/cabinet/library/page.tsx`**:
   - Список приобретенных электронных выкроек с актуальными номерами версий (v1, v2).
   - Бейджи статусов прав доступа (`Активно` / `Отозвано`).
   - Кнопка мгновенной генерации ссылки и скачивания PDF-лекала.
   - Блок загрузки пошаговых PDF-инструкций по пошиву.

9. **Центр безопасного скачивания (`/cabinet/downloads`) — `src/app/cabinet/downloads/page.tsx`**:
   - Выбор модели и версии для загрузки (актуальная или архивная).
   - Генерация защищенных подписанных URL с ограниченным сроком действия (TTL 60 минут).
   - Памятка по точной печати лекал: проверка масштаба 100%, калибровочного квадрата 10 × 10 см и схемы склейки.

### 2.2. Сервисы состояния и компоненты общего назначения

- **`Navbar` (`src/components/layout/Navbar.tsx`)**: Адаптивная навигация, логотип цифрового ателье, счетчик товаров в корзине, меню личного кабинета, мобильное меню-шторка.
- **`Footer` (`src/components/layout/Footer.tsx`)**: Баннер ценностей ателье, ссылки на разделы, информация о валюте расчетов (KGS) и юридический копирайт.
- **`AuthProvider` (`src/lib/auth-context.tsx`)**: Реактивное управление состоянием пользователя, логин, регистрация, выход, автоматическая подгрузка `/api/v1/auth/me`.
- **`CartProvider` (`src/lib/cart-context.tsx`)**: Управление корзиной с серверной синхронизацией через `/api/v1/cart/*`.
- **`ProductCard` (`src/components/catalog/ProductCard.tsx`)**: Премиальная карточка товара в каталоге с бейджами уровня сложности и ценой в KGS.
- **`CatalogFilters` (`src/components/catalog/CatalogFilters.tsx`)**: Боковая панель фильтрации по категориям, размерам, ростовкам и форматам.

## 3. Интеграция с Backend API

| Эндпоинт Backend | Метод | Использование на Frontend |
| :--- | :---: | :--- |
| `/api/v1/auth/register` | `POST` | Регистрация нового покупателя |
| `/api/v1/auth/login` | `POST` | Вход по email и паролю |
| `/api/v1/auth/me` | `GET` | Получение профиля текущего пользователя |
| `/api/v1/auth/logout` | `POST` | Завершение пользовательской сессии |
| `/api/v1/catalog/categories` | `GET` | Загрузка дерева категорий для меню и каталога |
| `/api/v1/catalog/filters` | `GET` | Справочник доступных размеров, ростовок и форматов |
| `/api/v1/catalog/products` | `GET` | Получение витрины выкроек с пагинацией и фильтрами |
| `/api/v1/catalog/products/:slug` | `GET` | Карточка модели и ее доступные варианты |
| `/api/v1/cart` | `GET` | Загрузка состава корзины и серверного итога в сомах |
| `/api/v1/cart/items` | `POST` | Добавление выбранного варианта выкройки |
| `/api/v1/cart/items/:id` | `DELETE` | Удаление позиции из корзины |
| `/api/v1/cart` | `DELETE` | Полная очистка корзины |
| `/api/v1/orders/checkout` | `POST` | Оформление заказа из корзины |
| `/api/v1/orders` | `GET` | История заказов покупателя |
| `/api/v1/cabinet/library` | `GET` | Получение библиотеки купленных выкроек |
| `/api/v1/cabinet/files/:id/download-url` | `POST` | Генерация временной защищенной ссылки на PDF-лекало |
| `/api/v1/cabinet/instructions/:id/download-url` | `GET` | Получение ссылки на скачивание инструкции по пошиву |
