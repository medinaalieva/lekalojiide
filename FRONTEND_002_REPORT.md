## 2. Обнаруженные и исправленные проблемы

| № | Область | Обнаруженный недочёт | Выполненное исправление |
| :-: | :--- | :--- | :--- |
| **1** | **TTL ссылок скачивания** (`/cabinet/downloads`, `/cabinet/library`) | Текст интерфейса ошибочно сообщал об истечении ссылки через 60 минут, тогда как реальный безопасный TTL бэкенда составляет **600 секунд (10 минут)**. | Текст в `downloads/page.tsx` и `library/page.tsx` скорректирован на точное значение: *«Ссылка действительна ... (10 минут / 600 секунд в соответствии с безопасным TTL backend)»*. TTL на фронтенде не увеличивался. |
| **2** | **Способы оплаты** (`/checkout`) | Карты (Элкарт, Visa, MC) и кошельки (MBank, О!Деньги) отображались единым блоком как активные шлюзы, хотя реальные банковские договоры эквайринга еще не подключены. | Недоступные реальные шлюзы переведены в статус `В процессе подключения` (неактивны для выбора). Единственным активным способом явно обозначен **«Тестовый платежный шлюз (KGS Sandbox)»** с понятным описанием симуляции оплаты. |
| **3** | **Touch-навигация и меню профиля** (`Navbar.tsx`) | На планшетах и сенсорных экранах выпадающее меню профиля на базе `group-hover` могло быть недоступно при тапе. | Добавлено интерактивное состояние `userMenuOpen` с открытием по клику, автозакрытием при клике вне меню (`handleClickOutside`) и при переходе по маршрутам. |
| **4** | **Селектор вариантов выкройки** (`/catalog/[slug]`) | При смене размера выбранная ростовка или формат могли отсутствовать для нового размера, сбрасывая активный вариант. | Добавлены `useEffect`-хуки автосогласования: при смене размера ростовка и формат автоматически корректируются на первый доступный для этой комбинации. |
| **5** | **Безопасность токенов и сессий** (`api.ts`, `auth-context.tsx`) | Запросы fetch не передавали `credentials: "same-origin"`, из-за чего HttpOnly cookie `refreshToken` мог теряться при фоновой ротации. | В сетевой клиент добавлен `credentials: "same-origin"`, в `auth-context.tsx` реализована автоматическая ротация токенов при получении 401 Unauthorized через `POST /api/v1/auth/refresh`. В коде фронтенда отсутствуют любые секреты. |

## 3. Проверенные страницы

Все ключевые разделы проверены с фактическим статусом HTTP 200 OK:

1. **Главная страница (`/`)** — отображение hero-баннера, адаптивной сетки категорий, новинок каталога, преимуществ цифрового ателье и подвала с валютой KGS.
2. **Каталог выкроек (`/catalog`)** — работа поисковой строки, боковых фильтров по категориям, размерам, ростовкам и форматам, сортировки и пагинации.
3. **Карточка товара (`/catalog/:slug`)** — фотогалерея, корректный конфигуратор размеров/ростовок/форматов, динамический пересчет цен в сомах, нормы расхода ткани и добавление в корзину.
4. **Корзина (`/cart`)** — перечень товаров, расчет итоговой суммы в сомах (KGS), удаление позиций, очистка корзины и переход к оформлению.
5. **Оформление заказа (`/checkout`)** — предзаполнение контактов авторизованного пользователя, разделение доступных/недоступных способов оплаты, успешное создание заказа.
6. **Авторизация (`/login`)** — валидация полей, понятный вывод ошибок аутентификации, сохранение сессии.
7. **Регистрация (`/register`)** — создание аккаунта нового покупателя с валидацией имени, телефона и пароля.
8. **Личный кабинет (`/cabinet`)** — сводка профиля, быстрые ссылки, история заказов с бейджами статусов оплаты.
9. **«Мои выкройки» (`/cabinet/library`)** — отображение прав доступа (`Активно` / `Отозвано`), актуальных версий лекал и скачивание PDF-инструкций по пошиву.
10. **Центр скачивания (`/cabinet/downloads`)** — безопасная генерация одноразовых signed URL со сроком жизни 600 секунд (10 мин) и памятка по правильной печати (100% масштаб).

## 5. Оставшиеся ограничения

1. **Реальные коммерческие платежные шлюзы:** Подключение боевых шлюзов (Freedom Pay, MBank, О!Деньги) требует регистрации юридического лица/ИП, заключения договоров интернет-эквайринга с банками Кыргызстана и получения production API-ключей. В настоящее время в проекте безопасно работает сертифицированный тестовый шлюз KGS Sandbox.
2. **Внешнее объектное хранилище S3:** В текущей тестовой конфигурации используется локальный Storage Mock с HMAC-подписью Presigned URL; подключение боевого бакета (Yandex Cloud / AWS / MinIO) конфигурируется через переменные окружения при релизе инфраструктуры.
