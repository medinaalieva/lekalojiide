## 2. Раздельный статус проверки Admin UI

### 2.1. Desktop Admin UI (1280 × 800) — СТАТУС: PASS
- **Авторизация:** Проверена работа шлюза `AdminLayout` под реальной учетной записью администратора `admin@lekalojiide.com`. Защитный экран «Доступ ограничен» не блокирует работу администратора.
- **Главный дашборд (`/admin`):** Сводная статистика, навигационные вкладки и быстрый переход в магазин работают без задержек.
- **Таблица выкроек (`/admin/products`):** Выводятся реальные товары каталога с фото, ценами, количеством вариантов и статусами публикации.
- **Создание выкройки (`/admin/products/new`):** 23 поля ввода параметров, дропзоны фото и CAD-чертежа активны.
- **Редактирование параметров («Чолпон»):** Все поля формы заполняются данными из БД (базовая цена, пакетная цена, расписание скидок, расход ткани, мерки готового изделия, ссылки на CAD и видео).
- **Файлы и инструкции (`/admin/products/[id]/files`):** Таблица вариантов матрицы и дропзона загрузки инструкций функционируют корректно.
- **Справочники (`/admin/sizes`, `/admin/dictionaries`):** Таблицы размеров 40–60, ростовок и форматов плоттеров открываются и поддерживают добавление новых значений.

### 2.2. Mobile Admin UI (390 × 844 — iPhone 12/13/14) — СТАТУС: PASS / PARTIAL
- **Горизонтальный скролл:** Полностью отсутствует (`overflow = false`). Все таблицы и карточки укладываются в ширину 390 px.
- **Навигация:** Мобильная шапка позволяет перемещаться между всеми разделами через компактное горизонтальное меню.
